Problem & Solution
❌ The Critical Gaps in Traditional Platforms (LeetCode, HackerRank)
1. Blind I/O Matching: Platforms only test if Output == Expected. They cannot measure clean architecture, memory leaks, scope hygiene, or machine instruction efficiency.
2. Rampant AI Code Copy-Pasting: Over 65% of coding submissions are copied from ChatGPT or Copilot. Naive string/token checkers fail when students rename variables.
3. Sandbox Escape & Cloud Risks: Running untrusted candidate code on shared Docker kernels risks host takeover, fork-bombs, memory snooping, and socket exfiltration.
✅ The PolyCode Paradigm: "White-Box" Compiler Intelligence

2. Multi-Engine Plagiarism Radar: Combines Winnowing N-gram rolling hashes + AST isomorphism to detect LLM plagiarism regardless of renamed variables.
3. 4-Tier Zero-Trust Sandbox Fleet: Hardened with Google gVisor (`runsc`) user-space microkernels, Seccomp syscall filtering, and sub-4ms Redis job queues.
